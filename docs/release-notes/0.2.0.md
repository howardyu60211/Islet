## Before you upgrade

- **Install this version by hand.** 0.1.0 can't update itself: download `Islet-0.2.0.dmg` and drag Islet into Applications to replace the old copy. From 0.2.0 on, updates install automatically.
- **Clipboard history is now saved on disk** in `~/Library/Application Support/Islet/Clipboard`, so it survives quitting, updates and restarts. Clear it under Settings › Clipboard › Clear History…. Content that password managers mark as concealed is still never recorded.
- **Pomodoro no longer stops after a set number of rounds.** Rounds keep counting up; use Start Over to go back to round 1.
- macOS sees this version as a new app, so you may need to allow Bluetooth again, and re-add Islet under Full Disk Access (System Settings › Privacy & Security) for Focus alerts.

## New

- **Automatic updates**: Islet checks for new versions, downloads them in the background and installs them when you quit. Turn this off or check now in Settings › About, or choose Check for Updates… from the menu bar item.
- **Pinned clipboard entries**: pin an entry with the pin button on the preview or by right-clicking. Pinned entries stay at the top and are never removed automatically.
- **Choose how much clipboard history to keep**: 30, 50 (default), 100 or 200 entries, not counting pinned ones. Clearing asks first and can keep pinned entries.
- **The timer and Pomodoro run at the same time**: switching between them only changes the view. The collapsed island shows whichever ends first, the other one's button shows its time remaining, and each alerts when it finishes.

## Fixes

- Skipping in Pomodoro no longer makes the round number jump back and forth.
- The clipboard preview and its buttons no longer flash when you move to another entry.
- The clipboard wheel stays smooth with a long history.

## 升級前須知

- **這一版要手動安裝。** 0.1.0 沒辦法自己更新：請下載 `Islet-0.2.0.dmg`，把 Islet 拖進「應用程式」取代舊版。0.2.0 之後的版本會自動更新。
- **剪貼簿紀錄現在會存到磁碟**，位置是 `~/Library/Application Support/Islet/Clipboard`，結束 App、更新、重新開機後都還在。要刪除可以到設定「剪貼簿 › 清除紀錄…」。密碼管理器標示為隱藏的內容一樣不會記錄。
- **番茄鐘不再做完固定輪數就停。** 輪數會一直往上累計；要回到第 1 輪請按「從頭開始」。
- macOS 會把這一版當成新的 App，可能要重新允許藍牙；要有專注模式提示的話，也要到「系統設定 › 隱私權與安全性 › 完整磁碟取用權限」重新加入 Islet。

## 新功能

- **自動更新**：Islet 會自動檢查新版本、在背景下載，結束 App 時裝好。可以在設定「關於」關掉自動檢查或立即檢查，也可以從選單列圖示選「檢查更新…」。
- **釘選剪貼簿紀錄**：用預覽上的圖釘按鈕或右鍵釘選。釘選的排在最上面，不會被自動刪掉。
- **自己選剪貼簿保留幾筆**：30、50（預設）、100 或 200 筆，釘選的不算。清除前會先確認，也可以選擇保留釘選的。
- **計時器和番茄鐘可以同時跑**：切換只是換畫面。收合時顯示比較快結束的那個，另一個的按鈕會顯示剩餘時間，時間到時各自提醒。

## 修正

- 番茄鐘按「跳過」時，輪數不會再來回跳。
- 換選剪貼簿紀錄時，預覽和按鈕不會再閃。
- 紀錄很多時，剪貼簿滾輪一樣順暢。
